## 平台守则

### 内容守则

- 禁止发布煽动、美化暴力、犯罪的信息
- 禁止发布挑起仇恨的言论
- 禁止违反用户当地法律使用该平台

除此之外，我们提供法律允许范围内最大化的言论自由。
并且在取得确凿证据之前，您就是一个普通账户。

### 处罚规则

#### 言论违规

一般处罚包括：
- 将违规内容强制设为仅自己可见
- 如果用户最近三条或更多都是确认违规，那么将封禁发布功能12小时

在连续发布违规内容10条之后，账户将被限制发布内容并记录一次。
如果屡教不改（9次）或当地法院向我们提供传票要求删除，我们有权
- 删除您的账户
- 删除违规内容
- 保留证据
并恕不另行通知

#### 申诉

如果您认为您没有违规，是我们搞错了，可以发送相关信息到`fuckxcorp@867678.xyz`进行申诉；
您有无限次申诉机会，结果将会返回给您发送时的邮箱；
不过必须带上您的FuckXter用户名，否则我们无法定位问题。

FuckXter整体的代码是开放的，如无特殊说明，应该均按照[MoPL](https://867678.xyz/docs/mopl)协议授权。
