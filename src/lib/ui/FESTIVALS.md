# 节日主题

默认使用「随节日自动」，统一按北京时间（UTC+8）计算。页面跨午夜、从后台回到前台、系统深浅色变化及站内换页时都会重新检查。节日结束后恢复普通配色。手动选择会固定主题；关闭则不自动启用。深浅色设置独立保留。

| ---------- | --------------------------------------------- |

这些是网站主题持续时间，独立于法定假期。重叠时公历节日优先，随后按 festivals.ts 中的顺序选择。闰月不重复触发传统节日。除夕通过次日是否为正月初一判断，兼容腊月二十九及三十。

农历月首及清明、冬至的日期来自[香港天文台公历与农历日期对照表](https://www.hko.gov.hk/tc/gts/time/conversion.htm)，离线覆盖 1901—2100 年。原始年度文本为 https://www.hko.gov.hk/tc/gts/time/calendar/text/files/T2026c.txt（替换年份）。lunar-months.json 每年按六位一组编码：公历月、日、农历月各两位；闰月的农历月加 12。solar-terms.json 每年依次记录四月清明和十二月冬至的公历日。

优先使用离线历表以避免浏览器 ICU 农历换算在部分年份差一天。覆盖范围外的农历使用 Intl 中国历回退，节气不会使用固定日期猜测。

public/festivals 中包含各节日的生成背景与透明 Logo，以及轻量 SVG 顶部挂饰和浏览器图标。首页背景仅做模糊与深浅色混合，不作用于帖子正文。没有节日时恢复原字标及 Fx 图标。所有装饰均不接收点击。
