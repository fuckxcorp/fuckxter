# FuckXter

[在线页面](https://fuckxter.site)

FuckXter 是一个基于 Astro 和 Cloudflare 全家桶 的轻量社交平台。

名称：Fuck X (ago called twitter) = FuckXter

## 🚀 特性

- 类似X的界面体验，但体感明显快于X。
- 帖子线程功能，可以方便的查看帖子以及回帖。
- 可自定义媒体存储+使用FuckXter内置的存储。
- 没有推荐算法，纯按XX排序。给您清爽的社交媒体体验！

## ⏰ 起源

> 以下时间均以UTC+0800算

在2026年9月8日凌晨12:08分许 我的X(https://x.com/com0loquieras)被处于只读模式

随后我尝试申诉 但并无任何用途 而且尝试导出数据 我只收到一个冰冷的 “出错了。”

于是 我就想能否开发一个类似的社交平台但不无故封号 然后 这就是成品

就在2026年9月23日凌晨12:10分许 我的Telegram也被列为双向账户了

死因是我给别人发了小广告或者某些夸大事实的事情 我自查发现根本没有 我已提交申诉但他根本不鸟我

因此 FuckXter messages正式更名为FuckXChat
